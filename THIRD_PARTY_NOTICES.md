# Third-party notices

What the archive holds, serves or installs that others wrote, under which licence, and where its notices are. The archive's licences page (`/licences/`) links to each notice served to browsers. `tests/test_third_party_notices.py` checks that every vendored file is listed in its folder's README with its hash, that every Python package pinned in the requirements files is listed here at its version, and that the files named exist.

## The map's style

`maps/style.json` is generated by `maps/generate_style.mjs` from @protomaps/basemaps 5.7.2, whose code is under BSD-3-Clause (Protomaps LLC, Kelso Cartography), its visual design under CC0 and its tile schema, adapted from Tilezen, under MIT. Their notices are in [`maps/static/maps/style.LICENSE.txt`](maps/static/maps/style.LICENSE.txt), copied from the basemaps repository's `LICENSE.md` (the npm package has none).

## Programs the archive runs but does not ship

ffmpeg and ffprobe (LGPL or GPL, depending on the build; Ubuntu's is GPL) check and copy uploaded videos, as separate programs. GNU gettext (GPL) compiles the translations. The `pmtiles` tool (BSD-3-Clause) cuts the map's tiles, and Node.js (MIT) runs only on a developer's machine, to regenerate the map's style or the test vectors. None of them is part of the archive; a deployment that packages any of them, in a container image for instance, takes on its licence's terms for that package.
